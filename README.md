# PDF 解鎖 / 壓縮工具

在自己的電腦上**解除 PDF 密碼**或**壓縮 PDF 檔案大小**。檔案完全在本機處理，不會上傳到任何地方。
支援 **Windows 10 / 11** 與 **macOS**。

- **解鎖**：移除開啟密碼（需要知道密碼），以及禁止列印、複製、編輯等權限限制（不需要密碼）。
- **壓縮**：縮小 PDF 內的圖片，可選擇壓縮程度，或直接指定「壓到幾 MB 以下」。
- 可一次處理多個檔案，結果另存新檔，**不會覆蓋原檔**。

## Windows 使用教學

### 方法一：下載執行檔（推薦，不需安裝任何東西）

1. 到 [**Releases 下載頁**](https://github.com/163braces-translate/pdf-tool/releases/latest)，下載 **`PDFTool-Windows.exe`**。
2. 雙擊 `PDFTool-Windows.exe` 開啟。
3. 第一次開啟若出現藍色視窗「**Windows 已保護您的電腦**」：
   點「**其他資訊**」→「**仍要執行**」。（因為程式沒有購買微軟數位簽章，這是正常現象）
4. 之後雙擊就能直接使用。可以把 exe 放到桌面或任何資料夾。

> 💡 exe 啟動需要幾秒鐘解壓縮，請稍等視窗出現，不要連續雙擊。

### 方法二：從原始碼執行

適合想自行修改程式，或 exe 被防毒軟體擋住時使用。

1. 在本頁上方點綠色的「**Code**」→「**Download ZIP**」。
2. 對下載的 zip 按右鍵 →「**內容**」→ 勾選下方「**解除封鎖**」→「確定」。
3. 對 zip 按右鍵 →「**全部解壓縮**」。
   ⚠️ 一定要先解壓縮，不能在壓縮檔裡直接雙擊。
4. 打開解壓縮後的資料夾，雙擊「**`開啟_Windows.bat`**」。
   - **第一次**會自動安裝 Python 3.12 與所需套件，約 1–3 分鐘，需要網路。
   - 若電腦無法自動安裝，會開啟 Python 官網，請下載安裝 Python 3.12，
     安裝畫面最下方記得勾選「**Add python.exe to PATH**」，裝好後再雙擊一次。
5. 之後雙擊「`開啟_Windows.bat`」就會直接開啟程式。

（選用）雙擊「`打包_Windows.bat`」可自行產生 `dist\PDFTool.exe` 單一執行檔。

## Mac 使用教學

### 方法一：下載 App（推薦，適用 M1 / M2 / M3 / M4 等 Apple 晶片的 Mac）

1. 到 [**Releases 下載頁**](https://github.com/163braces-translate/pdf-tool/releases/latest)，下載 **`PDFTool-Mac.zip`**。
2. 雙擊 zip 解壓縮，得到 **`PDFTool.app`**，可拖到「**應用程式**」資料夾。
3. 第一次開啟會被系統阻擋（因為沒有向 Apple 付費簽章）：
   1. 先雙擊 `PDFTool.app`，出現警告後按「**完成**」或「**取消**」。
   2. 打開「**系統設定**」→「**隱私權與安全性**」，往下捲到「安全性」區塊。
   3. 看到「已阻擋 PDFTool」，點「**強制打開**」，輸入密碼後再按「**打開**」。
4. 之後雙擊就能直接使用。

> 若出現「**已損毀，無法打開**」，打開「終端機」貼上下面這行後按 Enter，再重新開啟即可：
> ```bash
> xattr -cr /Applications/PDFTool.app
> ```
> （如果 App 不在「應用程式」資料夾，請把路徑換成實際位置，也可以輸入 `xattr -cr ` 後把 App 拖進終端機視窗。）

> 不確定是哪種晶片？點左上角  →「關於這台 Mac」，「晶片」寫 Apple M 開頭就可以用方法一；
> 若寫 Intel，請使用方法二。

### 方法二：從原始碼執行（Intel Mac 也適用）

1. 在本頁上方點綠色的「**Code**」→「**Download ZIP**」，下載後雙擊解壓縮。
2. 在資料夾裡的「**`開啟_Mac.command`**」上 **按右鍵 →「打開」**（第一次必須用右鍵開啟）。
   若仍被阻擋，同樣到「系統設定」→「隱私權與安全性」點「**強制打開**」。
3. **第一次**會自動建立執行環境並安裝套件，約 1 分鐘，需要網路：
   - 若電腦有 Homebrew，會詢問是否安裝圖形介面元件，按 **Enter** 同意即可。
   - 若沒有合適的 Python，會開啟 Python 官網，請下載「**macOS 64-bit universal2 installer**」
     安裝 Python 3.12，裝好後再開一次。
4. 看到「✅ 已開啟，可以關閉這個視窗」後，終端機視窗可以關掉，程式會繼續執行。
5. 之後雙擊「`開啟_Mac.command`」就會直接開啟程式。

> 若雙擊後是用「文字編輯」打開程式碼，代表執行權限遺失。打開「終端機」，輸入 `cd ` （後面有空格），
> 把資料夾拖進終端機視窗後按 Enter，再執行：
> ```bash
> chmod +x 開啟_Mac.command 打包_Mac.command
> ```

（選用）雙擊「`打包_Mac.command`」可自行產生 `dist/PDFTool.app`。

## 程式操作說明

1. 點「**加入 PDF…**」選擇一個或多個檔案（可按住 Ctrl / ⌘ 多選）。
   清單會顯示頁數、大小，以及是否「需密碼」或「有限制」。
2. 勾選要做的「**操作**」：
   - **移除密碼與限制（解鎖）**
   - **壓縮**
   - 兩個都勾 → 解鎖並壓縮
3. 若檔案需要開啟密碼，填入「**開啟密碼**」（多個檔案密碼相同時只要填一次；密碼不對時會逐一詢問）。
4. 調整「**壓縮設定**」（只有勾選壓縮時才需要）：

   | 預設 | 解析度 | 品質 | 適合用途 |
   |---|---|---|---|
   | 高品質（輕度壓縮） | 200 DPI | 85 | 需要列印 |
   | **平衡（推薦）** | 150 DPI | 70 | 一般閱讀、Email 寄送 |
   | 小檔案 | 110 DPI | 55 | 上傳有大小限制的網站 |
   | 極限壓縮 | 72 DPI | 35 | 只求最小、畫質可犧牲 |

   - 也可以直接拖動「**圖片解析度 (DPI)**」與「**JPEG 品質**」滑桿自訂，數字越小檔案越小。
   - **指定目標大小**：輸入例如 `5` MB，程式會自動找出能小於 5 MB 且畫質最好的設定（會花比較久）。
   - **圖片轉灰階**：彩色圖片轉黑白，可再縮小一些。
   - **字型子集化**：只保留用到的字，對內嵌完整中文字型的 PDF 特別有效。
   - **移除中繼資料**：清除作者、建立軟體等資訊。
5. 選擇「**輸出位置**」：預設存在原檔旁邊，檔名會加上 `_compressed`、`_unlocked` 等字樣。
6. 按「**開始處理**」，完成後清單會顯示壓縮前後大小，可按「**開啟輸出資料夾**」查看結果。

## 常見問題

**Q：壓縮後檔案沒有變小？**
壓縮主要針對 PDF 裡的圖片（掃描檔、照片）。純文字的 PDF 本來就很小，縮小空間有限。
若壓縮結果反而比原檔大，程式會直接保留原內容。

**Q：只勾「壓縮」，加密的 PDF 會怎樣？**
會保留原本的密碼保護。若要同時移除密碼，請一起勾選「解鎖」。

**Q：忘記開啟密碼可以解鎖嗎？**
不行。「需密碼」的檔案必須知道密碼才能解鎖；只有「有限制」（能開啟但不能列印、複製）的檔案不需要密碼。

**Q：防毒軟體說 exe 有病毒？**
用 PyInstaller 打包、沒有數位簽章的程式偶爾會被誤判。可以改用「方法二：從原始碼執行」。

**Q：檔案會被上傳嗎？**
不會。所有處理都在你的電腦上完成。只有第一次安裝套件時（方法二）需要網路。

## 開發者說明

### 檔案結構

```
開啟_Mac.command / 開啟_Windows.bat      雙擊開啟（第一次自動安裝環境）
打包_Mac.command / 打包_Windows.bat      雙擊打包成獨立 App / exe
tools/setup_mac.sh, tools/setup_win.bat    上面兩者共用的環境安裝邏輯
main.py                程式進入點
pdftool/core.py        解鎖、壓縮邏輯（不依賴介面，可單獨匯入）
pdftool/gui.py         Tkinter 圖形介面
requirements.txt       相依套件（PyMuPDF、Pillow）
.github/workflows/     GitHub Actions：自動打包並發布
```

執行環境分別裝在 `.venv-mac`、`.venv-win`；要重新安裝時刪掉對應資料夾再雙擊即可。

### 直接用指令執行

```bash
pip install -r requirements.txt
python main.py
```

### 發布新版本

推送 `v` 開頭的標籤，GitHub Actions 會自動打包 Windows exe 與 Mac App 並發布到 Releases：

```bash
git tag v1.0.1
git push origin v1.0.1
```
