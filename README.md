# PDF 解鎖 / 壓縮工具

在自己的電腦上**解除 PDF 密碼**或**壓縮 PDF 檔案大小**。檔案完全在本機處理，不會上傳到任何地方。

- **解鎖**：移除開啟密碼（需要知道密碼），以及禁止列印、複製、編輯等限制（不需要密碼）。
- **壓縮**：縮小 PDF 內的圖片，可選擇壓縮程度，或直接指定「壓到幾 MB 以下」。
- 可一次處理多個檔案，結果另存新檔，**不會覆蓋原檔**。

## Windows 使用教學

不需要安裝，下載後雙擊就能用。

### 第一次開啟

1. **下載**：點上方的「⬇ PDFTool-Windows.exe」。
   - 若 Edge 顯示「**PDFTool-Windows.exe 通常不會下載**」：
     把滑鼠移到該下載項目 → 點「**…**」→「**保留**」→「**顯示更多**」→「**仍要保留**」。
   - 若 Chrome 顯示「**不常下載的檔案**」：點「**保留**」。
2. **移動檔案（建議）**：到「下載」資料夾，把 `PDFTool-Windows.exe` 移到桌面或你習慣的資料夾。
3. **雙擊** `PDFTool-Windows.exe`。
4. 出現藍色視窗「**Windows 已保護您的電腦**」時：
   點「**其他資訊**」→ 點下方出現的「**仍要執行**」。
   （程式沒有購買微軟數位簽章才會出現，只有第一次需要這樣做）
5. 等候約 **5–10 秒**，程式視窗就會出現。等待期間不要重複雙擊。

### 之後使用

直接雙擊 `PDFTool-Windows.exe` 即可。

> **建立桌面捷徑**：在 exe 上按右鍵 →「**顯示其他選項**」→「**傳送到**」→「**桌面 (建立捷徑)**」。

## Mac 使用教學

適用 Apple 晶片的 Mac。Intel Mac 請改用[從原始碼執行](#從原始碼執行)。

### 第一次開啟

1. **下載**：點上方的「⬇ PDFTool-Mac.zip」。
   Safari 通常會自動解壓縮；若沒有，到「下載項目」雙擊 `PDFTool-Mac.zip`，會得到 `PDFTool`（App）。
2. **安裝**：把 `PDFTool` 拖到 Finder 側邊欄的「**應用程式**」資料夾。
3. **雙擊** `PDFTool`。第一次會出現「**無法打開「PDFTool」**」或「**Apple 無法驗證…**」的警告，
   按「**完成**」或「**好**」關閉（程式沒有向 Apple 付費簽章才會出現）。
4. **允許開啟**：
   1. 打開「**系統設定**」→ 左側點「**隱私權與安全性**」。
   2. 往下捲到「**安全性**」區塊，會看到「已阻擋 PDFTool…」。
   3. 點旁邊的「**強制打開**」，輸入 Mac 登入密碼（或 Touch ID）。
   4. 再跳出確認視窗時，點「**強制打開**」或「**打開**」。
5. 程式視窗出現就完成了，之後不會再詢問。

> **macOS 14 或更舊的版本**也可以用另一種方法：在 `PDFTool` 上**按右鍵 →「打開」→「打開」**。

> **出現「已損毀，無法打開」？** 打開「**終端機**」（在「應用程式」→「工具程式」裡），
> 貼上下面這行並按 Enter，再重新開啟 App：
> ```bash
> xattr -cr /Applications/PDFTool.app
> ```

### 之後使用

從「應用程式」資料夾或啟動台（Launchpad）點 `PDFTool` 即可。
想放在 Dock：開啟後在 Dock 圖示上按右鍵 →「**選項**」→「**保留在 Dock 中**」。

## 使用步驟

1. 點「**加入 PDF…**」選擇檔案（按住 `Ctrl`（Windows）或 `⌘`（Mac）可一次選多個）。
   清單會顯示頁數、大小，以及「需密碼」或「有限制」。
2. 在「**操作**」勾選要做的事：
   - **移除密碼與限制（解鎖）**
   - **壓縮**
   - 兩個都勾 → 解鎖並壓縮
3. 檔案若「需密碼」，在「**開啟密碼**」欄填入。多個檔案密碼相同只需填一次；密碼不對時程式會逐一詢問。
4. （壓縮時）選擇「**壓縮設定**」：

   | 預設 | 適合用途 |
   |---|---|
   | 高品質（輕度壓縮） | 需要列印 |
   | **平衡（推薦）** | 一般閱讀、Email 寄送 |
   | 小檔案 | 上傳有大小限制的網站 |
   | 極限壓縮 | 只求最小，畫質可以犧牲 |

   - **手動調整**：拖動「圖片解析度 (DPI)」與「JPEG 品質」滑桿，數字越小檔案越小。
   - **指定目標大小**：勾選後輸入例如 `5`，程式會自動找出能小於 5 MB 且畫質最好的設定（較花時間）。
   - **圖片轉灰階**：彩色圖片改成黑白，可再縮小一些。
   - **字型子集化**：只保留用到的字，對內嵌完整中文字型的 PDF 特別有效。
   - **移除中繼資料**：清除作者、建立軟體等資訊。
5. 「**輸出位置**」預設存在原檔旁邊，檔名會加上 `_compressed`、`_unlocked` 等字樣。
6. 按「**開始處理**」。完成後清單會顯示處理前後的大小，按「**開啟輸出資料夾**」即可看到結果。

## 更新與移除

- **更新**：從[下載](#下載)重新下載最新版，取代舊的檔案即可。
- **移除**：Windows 直接刪除 `PDFTool-Windows.exe`；Mac 把 `PDFTool` 從「應用程式」拖到垃圾桶。
  程式不會在電腦留下其他檔案。

## 從原始碼執行

適用：**Intel Mac**、執行檔被防毒軟體擋住、或想自行修改程式。第一次需要網路，會自動安裝所需環境（約 1–3 分鐘）。

<details>
<summary><b>Windows 步驟</b></summary>

1. 在本頁上方點綠色的「**Code**」→「**Download ZIP**」。
2. 對下載的 zip 按右鍵 →「**內容**」→ 勾選下方「**解除封鎖**」→「**確定**」。
3. 對 zip 按右鍵 →「**全部解壓縮**」。⚠️ 一定要先解壓縮，不能在壓縮檔裡直接雙擊。
4. 打開解壓縮後的資料夾，雙擊「**`開啟_Windows.bat`**」。
   - 若出現「Windows 已保護您的電腦」，點「**其他資訊**」→「**仍要執行**」。
   - 第一次會自動安裝 Python 3.12 與所需套件，完成後自動開啟程式。
   - 若無法自動安裝，會開啟 Python 官網：下載安裝 Python 3.12，
     安裝畫面最下方務必勾選「**Add python.exe to PATH**」，裝好後再雙擊一次。
5. 之後雙擊「`開啟_Windows.bat`」就會直接開啟程式。

（選用）雙擊「`打包_Windows.bat`」可自行產生 `dist\PDFTool.exe`。

</details>

<details>
<summary><b>Mac 步驟</b></summary>

1. 在本頁上方點綠色的「**Code**」→「**Download ZIP**」，下載後雙擊解壓縮。
2. 在資料夾裡的「**`開啟_Mac.command`**」上**按右鍵 →「打開」**。
   若被阻擋，到「系統設定」→「隱私權與安全性」點「**強制打開**」。
3. 會開啟一個終端機視窗，第一次自動安裝所需環境：
   - 若詢問是否執行 `brew install python-tk@…`，按 **Enter** 同意。
   - 若電腦沒有合適的 Python，會開啟 Python 官網：下載「**macOS 64-bit universal2 installer**」
     安裝 Python 3.12，裝好後再開一次 `開啟_Mac.command`。
4. 看到「✅ 已開啟，可以關閉這個視窗」後，終端機視窗可以關掉，程式會繼續執行。
5. 之後雙擊「`開啟_Mac.command`」就會直接開啟程式。

> 若雙擊後是用「文字編輯」打開，代表執行權限遺失。打開「終端機」，輸入 `cd `（後面有空格），
> 把資料夾拖進終端機視窗後按 Enter，再執行：
> ```bash
> chmod +x 開啟_Mac.command 打包_Mac.command
> ```

（選用）雙擊「`打包_Mac.command`」可自行產生 `dist/PDFTool.app`。

</details>

## 常見問題

**Q：點下載連結出現 404 / 找不到頁面？**
這是私人專案，需要先登入**已被加入此專案**的 GitHub 帳號才能下載。也可以請專案擁有者直接把檔案傳給你。

**Q：壓縮後檔案沒有變小？**
壓縮主要針對 PDF 裡的圖片（掃描檔、照片）。純文字的 PDF 本來就很小，縮小空間有限。
若壓縮結果反而比原檔大，程式會直接保留原內容。

**Q：只勾「壓縮」，加密的 PDF 會怎樣？**
會保留原本的密碼保護。若要同時移除密碼，請一起勾選「解鎖」。

**Q：忘記開啟密碼可以解鎖嗎？**
不行。「需密碼」的檔案必須知道密碼；只有「有限制」（能開啟但不能列印、複製）的檔案不需要密碼。

**Q：防毒軟體說 exe 有病毒？**
沒有數位簽章的打包程式偶爾會被誤判。可以改用[從原始碼執行](#從原始碼執行)。

**Q：檔案會被上傳嗎？**
不會。所有處理都在你的電腦上完成。

## 開發者說明

### 檔案結構

```
開啟_Mac.command / 開啟_Windows.bat      雙擊開啟（第一次自動安裝環境）
打包_Mac.command / 打包_Windows.bat      雙擊打包成獨立 App / exe
tools/setup_mac.sh, tools/setup_win.bat    上面兩者共用的環境安裝邏輯
main.py                程式進入點（加上 --selftest 參數會執行自我檢查）
pdftool/core.py        解鎖、壓縮邏輯（不依賴介面，可單獨匯入）
pdftool/gui.py         Tkinter 圖形介面
pdftool/selftest.py    自我檢查（CI 用來確認打包結果能正常運作）
requirements.txt       相依套件（PyMuPDF 1.x、Pillow）
.github/workflows/     GitHub Actions：自動打包、自我檢查並發布
```

執行環境分別裝在 `.venv-mac`、`.venv-win`；要重新安裝時刪掉對應資料夾再雙擊即可。

### 直接用指令執行

```bash
pip install -r requirements.txt
python main.py
```

### 發布新版本

推送 `v` 開頭的標籤，GitHub Actions 會自動打包 Windows exe 與 Mac App、實際啟動做自我檢查，
通過後發布到 Releases：

```bash
git tag v1.0.1
git push origin v1.0.1
```
